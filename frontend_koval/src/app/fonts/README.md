# Fuentes locales

Se sirven con `next/font/local` para que el build no dependa de Google Fonts.

| Archivo | Origen | Licencia |
|---|---|---|
| `Geist-Variable.woff2`, `GeistMono-Variable.woff2` | paquete npm `geist@1.3.1` (Vercel) | SIL OFL 1.1 (`LICENSE-Geist.txt`) |
| `montserrat-latin-{700,800,900}-normal.woff2` | paquete npm `@fontsource/montserrat@5.1.0` | SIL OFL 1.1 (`LICENSE-Montserrat.txt`) |
| `inter-latin-wght-normal.woff2` | paquete npm `@fontsource-variable/inter@5.1.0` | SIL OFL 1.1 (`LICENSE-inter.txt`) |
| `oswald-latin-wght-normal.woff2` | paquete npm `@fontsource-variable/oswald@5.1.0` | SIL OFL 1.1 (`LICENSE-oswald.txt`) |
| `playfair-display-latin-wght-normal.woff2` | paquete npm `@fontsource-variable/playfair-display@5.1.0` | SIL OFL 1.1 (`LICENSE-playfair-display.txt`) |
| `outfit-latin-wght-normal.woff2` | paquete npm `@fontsource-variable/outfit@5.1.0` | SIL OFL 1.1 (`LICENSE-outfit.txt`) |

Las tipografías de la carta (Ajustes > Tipografía) son fuentes variables (todos los pesos en un archivo).
El subconjunto `latin` incluye los caracteres del español (á, é, ñ, ¿, ¡).
