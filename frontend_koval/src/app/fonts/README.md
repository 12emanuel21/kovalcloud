# Fuentes locales

Se sirven con `next/font/local` para que el build no dependa de Google Fonts.

| Archivo | Origen | Licencia |
|---|---|---|
| `Geist-Variable.woff2`, `GeistMono-Variable.woff2` | paquete npm `geist@1.3.1` (Vercel) | SIL OFL 1.1 (`LICENSE-Geist.txt`) |
| `montserrat-latin-{700,800,900}-normal.woff2` | paquete npm `@fontsource/montserrat@5.1.0` | SIL OFL 1.1 (`LICENSE-Montserrat.txt`) |

El subconjunto `latin` de Montserrat incluye los caracteres del español (á, é, ñ, ¿, ¡).
